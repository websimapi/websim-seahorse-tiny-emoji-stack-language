Language summary

      
    
        
  • Program is a sequence of runs of the seahorse emoji (🧜‍♂️). Each contiguous run length (count) is an opcode or value.
    • 
        
  • Counts 1–9 push that integer to the stack.
    • 
        
  • 10 = ADD (pop a, b → push b + a). 11 = SUB (b - a). 12 = MUL. 13 = DIV (integer, handle div by 0). 14 = PRINT (pop and append to output). 15 = DUP (duplicate top). 16 = POP. 17 = READ (push number from Input field; 0 if empty or invalid). 18 = JMP (pop target index and set instruction pointer). 19 = JZ (pop value and target; if value==0 jump to target). 20 = HALT.
    • 
        
  • Any other counts are ignored with a trace warning.
    •
